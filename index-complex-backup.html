ملاحظة الحظر المهمة

ما الذي قد يتأثر فعلًا؟

شفافية قبل الاستخدام
المقصود بالحظر في الجزء المجاني: حظر حساب أو مفتاح مزود الذكاء الاصطناعي نفسه — مثل حساب Kiro أو Antigravity أو API key — وليس حظر رقم واتساب العميل.
رقم واتساب لا يُحظر تلقائيًا بسبب تبديل مزود AI. لكن يمكن أن يتأثر حساب Meta/WhatsApp إذا أرسل النظام رسائل مخالفة، spam، أو خالف سياسات Meta. لذلك فصلنا المسارين: فشل مزود الذكاء الاصطناعي → fallback؛ مخالفة WhatsApp → مشكلة مستقلة في Meta.
الحد الصريح: لا تلصق OAuth أو توكن جلسة Kiro/Antigravity هنا. النظام يدعم API رسميًا موثقًا فقط. البطاقتان موجودتان لتوضيح الحالة، وموقوفتان افتراضيًا؛ لا يوجد وعد بأن الاشتراك المجاني يصلح SaaS متعدد العملاء.
